# Nascar Racing Season 2003 Cam Patcher
**Important, before using the .exe it is advisable to backup your nr2003.exe file**


1. Close your game and open the .exe patcher
2. Browse your desired nr2003.exe
3. Choose your fov and set your camera offset
4. Click on "Apply to NR2003.exe"
5. The game will create a backup file that can be used to revert to the version before the first cam patch
6. Enjoy your new cam fov and offset


_The program will prompt an error window after closing for the first time because it doesn't have a proper shutdown_
